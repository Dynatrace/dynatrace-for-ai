# Dashboards Classic

**Gen3 replacement**: Dashboards, Notebooks

**Phase 2 required**: no

## What changes

Upgrade will simplify your user interface and keep the Dashboards and Notebooks app, while removing Dashboards Classic, Data Explorer, Metrics, and Reports.

## Customer actions

- Migrate Dashboards Classic to Dashboards using the provided migration functionality in the Dashboards Classic app
- Create necessary Notebooks for Data Explorer, Metrics, and Reports use cases

## Tracking queries

The Readiness Dashboard will include a link to a page with the popular dashboards to prioritize migration. New dashboards usage can be included as a success metric.
