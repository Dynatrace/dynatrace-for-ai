# Log v2

**Gen3 replacement**: Logs on Grail

**Phase 2 required**: no

## What changes

Upgrade will enable Logs powered by Grail with powerful analytics and retention capabilities. All settings from Log Classic will be migrated.

## Customer actions

- Prepare for the upgrade to Grail
- Classic log monitoring will no longer be available after Phase 3
